# Customer Churn Analytics Dashboard

## Project Overview
Customer Churn Analytics is an interactive Power BI dashboard designed to analyze customer behavior, identify churn patterns, and explore customer retention opportunities.

The dashboard helps businesses understand why customers leave and how retention strategies can reduce customer churn.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## Dataset
IBM Telco Customer Churn Dataset.

- Total Customers: 7,043
- Churned Customers: 1,869
- Retained Customers: 5,174

## Dashboard Pages

### 1. Customer Pulse
- Total Customers
- Churned Customers
- Churn Rate
- Retained Customers
- Average Monthly Charges
- Average Tenure
- Interactive customer filters

### 2. Journey Explorer
- Churn across customer tenure
- Churn rate by tenure stage
- Average monthly charges by tenure
- Customers by service count
- Churned customers by lifecycle

### 3. Retention Simulator
- What-if parameter for churn reduction
- Projected churned customers
- Customers saved
- Customer lifecycle-based retention analysis

## Key Features
- Interactive slicers and navigation buttons
- Customer lifecycle analysis
- Churn trend analysis
- Dynamic KPI cards
- What-if retention simulation
- Dark-themed dashboard design
